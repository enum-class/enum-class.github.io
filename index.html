Research

Safer software through better automation.

I work at the boundary of systems, programming languages, and automated software engineering—especially where program analysis and language models can make large-scale code transformation more dependable.

01

Safe C → Rust translation

Repository-level translation from unsafe C into compilable, idiomatic, memory-safe Rust.

02

Static analysis for synthesis

Identifying unsafe code patterns and using analysis results to guide safer code generation.

03

Programming agents

Studying how autonomous coding agents plan, drift, recover, and respond to corrective steering.

Publications

Selected research

Recent work on programming agents, repository-scale C-to-Rust translation, and evaluation of code reasoning.

ASE 2026 · Accepted 2026

From Plan to Action: How Well Do Agents Follow the Plan?

Shuyang Liu, Saman Dehghan, Jatin Ganhotra, Martin Hirzel, Reyhaneh Jabbarvand

Evaluates plan compliance in autonomous programming agents across 21,120 trajectories and studies how plan quality, reminders, and model strategy affect issue resolution.

arXiv ACM
Under publication 2026

Online Monitoring and Corrective Steering of Programming Agents

Shuyang Liu, Saman Dehghan, Ji Young Kim, Jatin Ganhotra, Martin Hirzel, Reyhaneh Jabbarvand

Introduces LivePlan, which monitors programming-agent trajectories and provides targeted corrective steering when agents drift, repeat failed actions, or terminate prematurely.

arXiv
Under publication 2025

Translating Large-Scale C Repositories to Idiomatic Rust

Saman Dehghan, Tianran Sun, Tianxiang Wu, Zihan Li, Reyhaneh Jabbarvand

Presents Rustine, a fully automated repository-scale C-to-Rust translation pipeline. Across 23 C programs, it generated compilable Rust for all programs and achieved 87% functional equivalence.

arXiv
Literature review 2024

Assessing Code Reasoning in Large Language Models: A Literature Review of Benchmarks and Future Directions

Saman Dehghan

Reviews benchmark design and evaluation frameworks for LLM code reasoning, including program logic, execution behavior, semantic understanding, and limitations of conventional evaluation.
