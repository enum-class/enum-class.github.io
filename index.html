Overview & Research Focus

Bridging High-Performance Systems & AI for Software Engineering

I am a Systems Software Engineer and graduate researcher at the University of Illinois Urbana-Champaign (UIUC), working in the Intelligent-CAT Lab. With nearly a decade of hands-on industry experience in low-latency C and C++, I specialize in constructing scalable, fault-tolerant distributed systems, network security appliances, real-time trading engines, and high-performance multithreaded data processors.

My current research sits at the intersection of Programming Languages (PL), Software Engineering (SE), and Large Language Models (LLMs). Specifically, I focus on:

  • Automated C-to-Rust Translation: Eliminating unsafe memory bugs by translating legacy C systems into idiomatic, verifiable safe Rust (Rustine).
  • Autonomous Programming Agents: Analyzing plan compliance, drift detection, and online corrective steering for SWE agents (ASE '26, LivePlan).
  • Static Analysis & Compilers: Upstream LLVM/Clang profiling, coverage instrumentation (MC/DC), and kernel hypervisor internals (Xen).
  • High-Throughput Systems: SIMD vectorization, Linux io_uring async runtimes, kernel bypass (DPDK/Netmap), and lock-free concurrency.

ASE 2026 Conference Paper arXiv:2604.12147

From Plan to Action: How Well Do Agents Follow the Plan?

Shuyang Liu, Saman Dehghan, Jatin Ganhotra, Martin Hirzel, Reyhaneh Jabbarvand

Investigates whether autonomous programming agents adhere to user/system generated plans during complex software development tasks. Evaluated over 21,120 SWE-agent trajectories across four state-of-the-art LLMs, eight plan variations, on SWE-bench Verified and SWE-bench Pro. Uncovers core dynamics of agent compliance, how structured phases influence issue resolution, and when reminders prevent plan deviation.

Under Publication Preprint arXiv:2608.06701

Online Monitoring and Corrective Steering of Programming Agents (LivePlan)

Shuyang Liu, Saman Dehghan, Ji Young Kim, Jatin Ganhotra, Martin Hirzel, Reyhaneh Jabbarvand

Introduces LivePlan, an execution framework that monitors programming agent trajectories in real time and applies corrective steering when agents drift or execute repetitive invalid actions. Separates deterministic rule-based triggers from LLM advisors, yielding up to 15.2% improvement (avg. 9.9%) in issue resolution on SWE-bench at a modest cost of $0.08 per instance.

arXiv:2608.06701
Under Publication Preprint arXiv:2511.20617

Translating Large-Scale C Repositories to Idiomatic Rust (Rustine)

Saman Dehghan, Tianran Sun, Tianxiang Wu, Zihan Li, Reyhaneh Jabbarvand

Presents Rustine, a fully automated repository-level pipeline that translates unsafe C codebases into idiomatic, memory-safe Rust. Evaluated on 23 C repositories up to 13,200 LOC, achieving 87% functional equivalence across 1,221,192 test assertions, drastically minimizing raw pointer usage, unsafe blocks, and compiler linter warnings compared to six baseline methods.
